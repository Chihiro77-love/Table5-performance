====================================================================
 BENCHMARK DATASET - PROVENANCE AND EXACT SELECTION
====================================================================

SOURCE
------
USC-SIPI Image Database (Signal and Image Processing Institute,
University of Southern California), "misc" volume:

    https://sipi.usc.edu/database/
    direct download: https://sipi.usc.edu/database/misc.zip

The 39 images of the misc volume are used exactly as distributed by
the database (uncompressed .tiff files; no conversion, resizing or
re-encoding). The benchmark redistributes only the 20 selected images
plus the representative image (below); the remaining 19 images of the
pool are not redistributed and are obtained from the official URL.

CONTENTS OF THIS FOLDER
-----------------------
    usc-sipi_4.2.03_mandrill.tif
        Representative input for the quantitative N-repeat run
        (standard test image 4.2.03, "Mandrill"/"Baboon",
        512x512 24-bit RGB TIFF, 786,572 bytes). Byte-identical to
        random20_images/4.2.03.tiff (same SHA-256).

    random20_images/*.tiff
        The 20 images randomly selected from the 39-image pool.

    SHA256SUMS.txt
        SHA-256 hashes of every redistributed image.
        Verify:  shasum -a 256 -c SHA256SUMS.txt   (macOS/Linux)
                 certutil -hashfile <file> SHA256   (Windows, compare
                 against the listed value)

SELECTION PROCEDURE
-------------------
20 images were picked at random without replacement from the 39-image
pool. The draw was performed manually without a pseudo-random number
generator or a recorded seed, so the random draw itself is not
algorithmically replayable. The OUTCOME of the draw, however, is fixed
exactly and unambiguously: the 20 redistributed files together with
their SHA-256 hashes in SHA256SUMS.txt uniquely define the benchmark
dataset, and all benchmark results refer to these exact bytes.

The recorded set is checked by
04_Benchmark/benchmark_scripts/sample_selected20.py, which:
  - verifies the SHA-256 hashes of the 20 files against SHA256SUMS.txt
  - prints image ID / dimensions / size for each of the 20 images
  - if the full pool is present, asserts it contains exactly 39 .tiff
    files and that every selected image is a member of that pool

To run the membership check against the full 39-image pool:

    1. download https://sipi.usc.edu/database/misc.zip
    2. unpack it so that the 39 .tiff files are located at
       01_Datasets/benchmark_dataset/misc_raw/misc/*.tiff
       (i.e. misc.zip's inner "misc" folder, unchanged)
    3. run:  python 04_Benchmark/benchmark_scripts/sample_selected20.py
