Method_1: DNA-Fountain
======================
Third-party tool. Official upstream repository:

    https://github.com/TeamErlich/dna-fountain

Reference: Erlich, Y. and Zielinski, D., 2017. DNA Fountain enables a
universal and optimal approach to data storage. Science, 355(6328),
pp. 950-954.

PROVENANCE
----------
The upstream code is NOT redistributed inside this package. During
reproduction it is fetched (git clone) into:

    02_Software/DNA-Fountain/dna-fountain-master/

The exact revision executed is recorded in two complementary ways:
  1. the upstream git commit id:
       git -C 02_Software/DNA-Fountain/dna-fountain-master rev-parse HEAD
  2. SHA-256 hashes of every executed source file (*.py and *.pyx),
     written by 04_Benchmark/benchmark_scripts/add_source_hashes.py into
     04_Benchmark/results/main/environment.txt (section "source_file_hashes").

Python 3: the original code targets Python 2. If the current upstream
checkout does not build/run on Python 3 as-is, apply only
dependency-compatibility adjustments (print function, xrange -> range,
`from sets import Set` -> the built-in set, iterator .next() -> next(),
bytes/str handling in preprocessing.py); do not change any algorithmic
parameter. All algorithmic parameters used are recorded in
04_Benchmark/benchmark_config.yaml, section "method_1_dnafountain", and
are passed on the tool's command line by
04_Benchmark/benchmark_scripts/run_benchmark.py.

Build the Cython extensions before the first run (see
07_Reproduction/reproduction_commands.txt, STEP 2):

    python setup.py build_ext --inplace
